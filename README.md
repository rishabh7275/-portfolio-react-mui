# Raunak Tiwari — Portfolio

Responsive portfolio built with React, TypeScript, Vite, and Material UI.

## Run locally

```bash
npm install
npm run dev
```

## Before publishing
- Replace `your-email@example.com` in `src/App.tsx` with your real public email.
- Add your LinkedIn profile URL.
- Add the correct GitHub repository URL for Electricity Billing System and TaskFlow if available.
- Add a resume PDF to `public/assets/` and wire the download button if you want a resume link.
