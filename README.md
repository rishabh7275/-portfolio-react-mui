
# Rishabh Tiwari – Portfolio

A modern, responsive personal portfolio website built with React, TypeScript, Material UI, and Vite.

## Features

- Responsive and modern UI
- Dark and light theme
- Projects showcase
- Skills and experience sections
- Resume preview and download options
- Contact and social media links

## Tech Stack

- React
- TypeScript
- Material UI (MUI)
- Vite
- CSS

## Run Locally

```bash
git clone https://github.com/rishabh7275/-portfolio-react-mui.git
cd -portfolio-react-mui
npm install
npm run dev
```
